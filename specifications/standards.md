# Technische Standaarden

DD API is gebouwd op basis van gangbare open standaarden. 
Dit zorgt voor maximale interoperabiliteit en maakt het eenvoudig om aan te sluiten met bestaande tools en bibliotheken.

## Core Standaarden
- **🔗[OData](https://www.odata.org)** (Open Data Protocol) voor data-uitwisseling
- **🔗[CSDL](https://docs.oasis-open.org/odata/odata-csdl-xml/v4.01/odata-csdl-xml-v4.01.html)** (Common Schema Definition Language) voor OData metadata beschrijvingen
- **🔗[OpenAPI/Swagger](https://swagger.io/specification/)** voor API documentatie

## Data Formaten
- **🔗[JSON](https://www.json.org)** (JavaScript Object Notation) voor data structuren
- **🔗[GeoJSON](https://geojson.org)** voor geografische data
- **🔗[CoverageJSON](https://covjson.org/)** voor tijdsreeksen en voorspellingen
- **🔗[ISO 8601](https://www.iso.org/iso-8601-date-and-time-format.html)** voor datum/tijd formaten

## Domain Standaarden
- **🔗[Observations, Measurements & Samples](https://www.ogc.org/standard/om/)** voor het beschrijven van observaties en metingen

## API Gedrag
- **🔗[RFC 7807](https://datatracker.ietf.org/doc/html/rfc7807)** voor error responses
- **🔗[GitHub Rate Limiting](https://docs.github.com/en/rest/overview/resources-in-the-rest-api#rate-limiting)** voor API throttling
