# Voorbeelden van responses

## Observaties
- [Fysisch/Chemisch](physical_chemical.json) - Eenvoudig voorbeeld van fysisch/chemische data als losse observaties.
- [Ecologisch](ecological.json) - Voorbeeld van ecologische observaties.
- [Tijdreeks](timeseries.json) - Voorbeeld van waterhoogte als tijdreeks.
- [Verwachting](expectation.json) - Voorbeeld van een verwachting (waterhoogte).
- [Ensemble](ensemble.json) - Voorbeeld van waterdata met verschillende assen.

## Referenties
- [Meetobjecten (Locaties)](measurementobject_reference.json) - Meetlocaties worden in alle situaties gebruikt. Dit is de FoI (Feature of Interest) in DD API V3.
- [Grootheden](quantity_reference.json) - Grootheden worden in alle situaties gebruikt.
- [Biologie (Taxa)](taxa_reference.json) - Dit is een voorbeeld van een systeem dat diepe kennis heeft biologische taxa.
