# Bijdragen aan Digitale Delta API V3

Bedankt voor je interesse in het bijdragen aan de Digitale Delta API V3!

## Organisatiestructuur

De ontwikkeling en het beheer van de Digitale Delta API V3 wordt gecoördineerd door:

- **IHW (Informatiehuis Water)** - Verantwoordelijk voor procesbewaking en woordenboeken
- **Architecture Board** - Bepaalt de technische richting en beheert de technische aspecten
- **Gebruikersgroep** - Vertegenwoordigt de gebruikers en kan wijzigingsvoorstellen indienen

## Hoe kun je bijdragen?

### 1. Functionaliteit of Wijzigingen Voorstellen

Je kunt op twee manieren wijzigingsvoorstellen indienen:
- Via de gebruikersgroep
- Direct via een issue in deze repository

Beschrijf in je voorstel:
- Het probleem of de behoefte
- De voorgestelde oplossing
- De verwachte voordelen
- Mogelijke impact op bestaande implementaties

### 2. Issues Melden

Vind je een fout in de documentatie of specificatie?
- Open een issue in deze repository
- Beschrijf het probleem zo specifiek mogelijk
- Voeg eventueel een verbetervoorstel toe

### 3. Pull Requests

Wil je zelf verbeteringen aanbrengen?
1. Fork de repository
2. Maak je wijzigingen
3. Dien een pull request in
4. De Architecture Board zal je PR beoordelen

## Beoordelingsproces

1. Nieuwe voorstellen worden eerst beoordeeld door de Architecture Board
2. Bij grote wijzigingen wordt de gebruikersgroep geconsulteerd
3. IHW bewaakt het proces en de planning
4. Na goedkeuring wordt de wijziging doorgevoerd


## Code of Conduct

- Wees respectvol naar andere bijdragers
- Focus op constructieve feedback
- Houd discussies zakelijk en professioneel
